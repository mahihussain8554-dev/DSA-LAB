# Sorting Algorithms

This directory contains implementations of fundamental **sorting algorithms** using C and C++.

## Implementations

### Bubble Sort

Repeatedly compares adjacent elements and swaps them if they are in the wrong order.

* **Best Case:** `O(n)`
* **Average Case:** `O(n²)`
* **Worst Case:** `O(n²)`
* **Space:** `O(1)`

### Insertion Sort

Builds the sorted portion of an array one element at a time by inserting each element into its appropriate position.

* **Best Case:** `O(n)`
* **Average Case:** `O(n²)`
* **Worst Case:** `O(n²)`
* **Space:** `O(1)`

### Selection Sort

Repeatedly selects the minimum element from the unsorted portion and places it at the beginning.

* **Best Case:** `O(n²)`
* **Average Case:** `O(n²)`
* **Worst Case:** `O(n²)`
* **Space:** `O(1)`

### Merge Sort

Uses the **divide and conquer** technique by dividing the array into smaller parts, sorting them, and merging the sorted parts.

* **Best Case:** `O(n log n)`
* **Average Case:** `O(n log n)`
* **Worst Case:** `O(n log n)`
* **Space:** `O(n)`

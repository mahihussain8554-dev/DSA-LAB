# Max Heap

This directory contains an implementation of a **Max Heap** data structure using C.

## Overview

A Max Heap is a **complete binary tree** in which the value of every parent node is greater than or equal to the values of its children.

## Operations Covered

* Heap creation
* Insertion
* Deletion
* Heapify
* Extract maximum element
* Displaying heap elements

## Complexity

* **Insertion:** `O(log n)`
* **Deletion:** `O(log n)`
* **Get Maximum:** `O(1)`
* **Heapify:** `O(n)`

## Language

**C**

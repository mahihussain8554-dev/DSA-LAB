# Recursion and Backtracking

This directory contains implementations of fundamental **recursion and backtracking** problems using C++.

## Implementations

* `Fibonacci.cpp` — Fibonacci sequence using recursion
* `Factorial.cpp` — Factorial calculation using recursion
* `Permutations.cpp` — Generation of all possible permutations
* `Subsets.cpp` — Generation of all possible subsets
* `Sum.cpp` — Sum calculation using recursion
* `Valid_Parenthesis.cpp` — Generation and validation of balanced parentheses

## Concepts Covered

* Recursion
* Base and recursive cases
* Backtracking
* Decision trees
* Subset generation
* Permutation generation
* Combinatorial problem solving

## Language

**C++**

## Purpose

These implementations are part of my **Data Structures and Algorithms (DSA)** practice, focusing on recursion, backtracking, and their applications in solving combinatorial problems.

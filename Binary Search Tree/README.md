# Binary Search Tree

This directory contains implementations and fundamental operations related to **Binary Search Trees (BST)** using C and C++.

## Implementations

* Binary Search Tree creation
* Node insertion
* Tree traversal
* Searching
* BST-based operations
* Square root implementation using binary search

## Traversal Techniques

* Inorder Traversal
* Preorder Traversal
* Postorder Traversal

## Complexity

For a balanced Binary Search Tree:

* **Search:** `O(log n)`
* **Insertion:** `O(log n)`
* **Deletion:** `O(log n)`

In the worst case, when the tree becomes skewed:

* **Search:** `O(n)`
* **Insertion:** `O(n)`
* **Deletion:** `O(n)`

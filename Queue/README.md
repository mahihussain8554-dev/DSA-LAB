# Queue

This directory contains implementations of the **Queue** and **Circular Queue** data structures using C and C++.

## Implementations

### 1. Queue

**Files:**

* `queue_represention_with_c.c`
* `queue_represention_with_c++.cpp`

A Queue is a linear data structure that follows the **FIFO (First In, First Out)** principle.

**Operations:**

* Enqueue
* Dequeue
* Peek
* Display
* Overflow and Underflow handling

**Time Complexity:**

* Enqueue: `O(1)`
* Dequeue: `O(1)`
* Peek: `O(1)`

### 2. Circular Queue

**File:**

* `Circular_Queue.cpp`

A Circular Queue is an improved version of a linear queue where the last position is connected to the first position, allowing efficient utilization of available space.

**Operations:**

* Enqueue
* Dequeue
* Peek
* Display
* Overflow and Underflow handling

**Time Complexity:**

* Enqueue: `O(1)`
* Dequeue: `O(1)`
* Peek: `O(1)`

## Languages

* C
* C++

These implementations are part of my **Data Structures and Algorithms (DSA)** practice, focusing on queue operations, FIFO principles, and efficient memory utilization using circular queues.

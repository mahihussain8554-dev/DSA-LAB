# Dynamic Memory Allocation

This directory contains implementations demonstrating **dynamic memory allocation in C**.

## Overview

Dynamic memory allocation allows memory to be allocated and managed at runtime, providing flexibility when the required memory size is not known beforehand.

## Functions Covered

* `malloc()` — Allocates a specified amount of memory.
* `calloc()` — Allocates and initializes memory to zero.
* `realloc()` — Resizes a previously allocated memory block.
* `free()` — Releases dynamically allocated memory.

## Key Concepts

* Runtime memory allocation
* Heap memory management
* Dynamic arrays
* Memory resizing
* Proper memory deallocation

## Language

**C**

## Purpose

The implementations are intended to build a strong understanding of **heap memory management and dynamic data structures**, which are fundamental concepts in Data Structures and Algorithms.

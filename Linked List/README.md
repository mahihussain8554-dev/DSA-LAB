# Linked List

This directory contains implementations of the **Linked List** data structure using C.

## Overview

A Linked List is a linear data structure where elements are stored in individual **nodes**. Each node contains data and a pointer that connects it to the next node.

## Operations Covered

* Linked List creation
* Insertion
* Deletion
* Traversal
* Searching
* Updating nodes
* Displaying list elements

## Key Concepts

* Dynamic memory allocation
* Pointers
* Structures
* Node-based data organization
* Dynamic data structures

## Complexity

* **Insertion at beginning:** `O(1)`
* **Insertion at end:** `O(n)`
* **Deletion:** `O(n)`
* **Searching:** `O(n)`
* **Traversal:** `O(n)`

## Language

**C**
